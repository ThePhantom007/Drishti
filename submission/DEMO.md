1. Brief introduction to the problem (DR screening capacity in rural India).
2. The proposed solution (dual-path AI grading + human-in-the-loop review).
3. Main workflow: ASHA capture → AI grading → doctor review/override →

4. The actual working prototype — ideally the live deployment (see
   `docs/DEPLOYMENT.md`), not just localhost.
5. The Simulink capacity model and validation benchmarks, since these are
   differentiators for this problem statement specifically.

Keep the video focused on the actual project and make sure reviewers can
access it without requesting permission.
