# without MATLAB installed). Use this instead of
# python/requirements-gateway.txt when deploying -- it deliberately
# excludes matlabengine, which isn't installable/usable without an actual
# MATLAB installation matching its pinned version. The gateway already
# handles this at runtime (matlab_bridge.py falls back to its built-in
# mock-inference mode automatically when matlabengine can't be imported),
# so a deployment without MATLAB is a legitimate, fully working demo
# configuration -- not a broken one.
